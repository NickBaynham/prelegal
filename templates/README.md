# Legal Document Templates

This directory contains a curated set of standard legal agreement templates used by PreLegal as a starting point for generating new documents.

## Source

All templates are sourced from the [Common Paper](https://github.com/commonpaper) GitHub organization. Common Paper publishes a library of standard, plain-language agreements maintained by lawyers and intended to be reused by the broader community.
